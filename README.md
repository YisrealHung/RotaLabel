# RotaLabel

圖像標註桌面工具，支援 BBox 與旋轉框（OBB），並可產生含資料擴增的訓練資料集。

## 安裝

需要 Python 3.10 以上。

```bash
pip install -r requirements.txt
```

## 啟動

```bash
python main.py
```

也可以直接指定圖片資料夾：

```bash
python main.py D:\data\images
```

下次啟動會自動開啟上次的資料夾。

## 基本流程

1. 按 **開啟資料夾**（Ctrl+O），選擇放圖片的資料夾。
2. 在右側 **類別** 面板新增類別。
3. 按 `W` 畫 BBox，或按 `E` 畫旋轉框，在圖上拖曳出矩形。
4. 用 `A` / `D` 切換上一張 / 下一張。標註會自動儲存。
5. 標完後按 **產生資料集**（Ctrl+E），設定切分與擴增，匯出訓練資料。

## 標註操作

### 畫框

- BBox 與旋轉框的畫法相同：按住左鍵拖曳。
- 旋轉框畫好後，拖曳上方的黃色圓點即可旋轉；拖曳時按住 `Shift` 會以 15° 為單位吸附。
- 拖曳框邊上的小方塊可調整大小，旋轉後也會沿著框的方向調整。
- 拖曳框內部可移動位置。

### 選取框

- 選取模式（`V`）：點一下框即可選取。
- 在 BBox / 旋轉框模式下：用 `Ctrl` + 左鍵、右鍵或雙擊選取框。
- 也可以在右側 **此圖標註** 清單中點選。

### 快捷鍵

| 按鍵 | 功能 |
|---|---|
| `W` | 畫 BBox |
| `E` | 畫旋轉框 |
| `V` | 選取 / 編輯模式 |
| `Z` / `X` | 選取的框逆時針 / 順時針旋轉 1° |
| `Shift+Z` / `Shift+X` | 選取的框旋轉 15° |
| `T` | 選取的框在 BBox 與旋轉框之間切換 |
| `1`–`9` | 切換類別（有選取框時會同時變更它的類別） |
| `Delete` | 刪除選取的框 |
| 方向鍵 | 微調位置 1px（加 `Shift` 為 10px） |
| `Ctrl+C` / `Ctrl+V` | 複製 / 貼上框（可貼到其他圖片） |
| `Ctrl+Z` / `Ctrl+Y` | 復原 / 重做 |
| `A` / `D` | 上一張 / 下一張 |
| `F` | 圖片符合視窗 |
| `L` | 顯示 / 隱藏框上的標籤文字 |
| `Esc` | 取消選取 |
| 滾輪 / `Shift` + 滾輪 | 上下 / 左右捲動 |
| `Ctrl` + 滾輪 | 縮放 |
| 中鍵拖曳、空白鍵 + 左鍵拖曳 | 平移 |
| `F1` | 顯示快捷鍵說明 |

### 類別管理

在右側 **類別** 面板中：

- **＋ 新增**：新增類別
- **改名**：重新命名（也可雙擊類別）
- **顏色**：變更框的顏色
- **刪除**：刪除類別，會一併刪除所有圖片中這個類別的框

## 產生資料集（Ctrl+E）

視窗右側會即時預覽擴增結果：左上為原圖，其餘為隨機擴增樣本。按 **換一張圖片** 或 **重新隨機** 可以看其他結果。

1. **切分**：設定 Train / Valid / Test 比例和亂數種子。可勾選略過沒有標註的圖片。
2. **前處理**（套用到所有切分）：
   - Resize：不調整、拉伸，或等比例縮放並補黑邊
   - 轉灰階
3. **幾何擴增**（只套用到 Train，框會跟著轉換）：水平翻轉、垂直翻轉、90° 旋轉、任意角度旋轉、剪切、縮放、隨機裁切、左右 / 上下平移。
   - **平移**：分別設定 X、Y 方向最多隨機移動幾個像素（以前處理後的圖片為準），移開的區域補黑色。
   - **允許框超出邊界**：不勾選時會自動限制平移量，讓所有框完整留在圖內；勾選後可自由平移，超出的部分會被裁掉，並依「框保留門檻」決定是否保留。
4. **色彩 / 像素擴增**（只套用到 Train）：亮度、曝光、對比、飽和度、色相、灰階、模糊、雜訊。
5. **輸出**：
   - 每張 Train / Valid 圖輸出數量（包含原圖，最多 100）；Test 固定輸出 10 張
   - 框保留門檻：擴增後框留在圖內的面積低於此比例就捨棄
   - 匯出格式，可多選

按 **產生版本** 開始匯出。完成後可直接開啟輸出資料夾。

### 匯出格式

| 格式 | 標註內容 | 說明 |
|---|---|---|
| YOLO | `cls cx cy w h`（正規化） | 旋轉框會轉成外接矩形 |
| YOLO-OBB | `cls x1 y1 x2 y2 x3 y3 x4 y4`（正規化） | 可直接用於 ultralytics 旋轉框訓練；BBox 視為 0° 旋轉框 |
| DOTA | `x1 y1 ... x4 y4 類別名稱 difficult`（像素） | BBox 視為 0° 旋轉框 |
| COCO JSON | `bbox`、4 點 `segmentation` | 旋轉框另有 `rbox: [cx, cy, w, h, angle]` |
| COCO-OBB | `segmentation`（4 個順時針頂點，像素）、外接 `bbox`、多邊形 `area`、`category_id` 從 0 開始 | 給 PaddleDetection PP-YOLOE-R 使用；BBox 視為 0° 旋轉框 |

輸出資料夾結構（以 YOLO 為例）：

```
v1_20261105_103000/
├── data.yaml
├── version.json        # 本次設定，可用來重現
├── train/images, train/labels
├── valid/images, valid/labels
└── test/images,  test/labels
```

COCO-OBB 的結構不同，Valid 會輸出成 `val`：

```
coco_obb/
├── train/images
├── val/images
├── test/images
└── annotations/
    ├── train.json
    ├── val.json
    └── test.json
```

選擇多種格式時，每種格式各放在一個子資料夾。

## 匯入既有標註

**檔案 → 匯入標註**，選擇放 `.txt` 標註檔的資料夾（檔名需與圖片相同）。

- 自動辨識 YOLO、YOLO-OBB、DOTA 格式
- 若資料夾內有 `classes.txt` 或 `data.yaml`，會使用其中的類別名稱
- 可選擇取代或附加到現有標註

## 檔案位置

所有資料都存在圖片資料夾內：

```
<圖片資料夾>/rotalabel_project/
├── project.json        # 類別與設定
├── annotations/        # 每張圖一個 .json 標註檔
└── versions/           # 產生的資料集
```

每次存檔時，也會在圖片旁邊寫一份同檔名的 DOTA 標註檔（例如 `001.jpg` → `001.txt`）：

```
imagesource:rotalabel
gsd:null
x1 y1 x2 y2 x3 y3 x4 y4 類別名稱 0      # 像素座標，4 點順時針
```

- 第一行 `imagesource:rotalabel` 是 RotaLabel 的標記；資料夾裡原本就有、不是 RotaLabel 寫的 `.txt` 不會被覆蓋。
- 兩張圖檔名相同、副檔名不同時（例如 `a.jpg`、`a.png`），會改用 `a.jpg.txt`、`a.png.txt`。
- 開啟專案、類別改名時會自動更新；可以用「匯入標註」重新讀回。

舊版（BBoxer）建立的 `bboxer_project/` 資料夾仍可直接開啟使用。

## 其他

- **深色 / 淺色主題**：按工具列右側的 ◐ 按鈕，或選 **檢視 → 切換主題**。
- **角度**：以度為單位，正值為畫面上的順時針方向。
- **測試**：`python -m pytest -q`
