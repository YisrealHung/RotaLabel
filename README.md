# RotaLabel

圖像標註桌面工具，支援 BBox 與旋轉框（OBB），並可產生含資料擴增的訓練資料集。

## 安裝

需要 Python 3.10 以上。

```bash
pip install -r requirements.txt
```

## 啟動

```bash
python main.py
```

也可以直接指定圖片資料夾：

```bash
python main.py D:\data\images
```

下次啟動會自動開啟上次的資料夾。

## 基本流程

1. 按 **開啟資料夾**（Ctrl+O），選擇放圖片的資料夾。
2. 在右側 **類別** 面板新增類別。
3. 按 `W` 畫 BBox，或按 `E` 畫旋轉框，在圖上拖曳出矩形。
4. 用 `A` / `D` 切換上一張 / 下一張。標註會自動儲存。
5. 標完後按 **產生資料集**（Ctrl+E），設定切分與擴增，匯出訓練資料。

## 標註操作

### 畫框

- BBox 與旋轉框的畫法相同：按住左鍵拖曳。
- 旋轉框畫好後，拖曳上方的黃色圓點即可旋轉；拖曳時按住 `Shift` 會以 15° 為單位吸附。
- 拖曳框邊上的小方塊可調整大小，旋轉後也會沿著框的方向調整。
- 拖曳框內部可移動位置。

### 選取框

- 選取模式（`V`）：點一下框即可選取。
- 在 BBox / 旋轉框模式下：用 `Ctrl` + 左鍵、右鍵或雙擊選取框。
- 也可以在右側 **此圖標註** 清單中點選。

### 快捷鍵

| 按鍵 | 功能 |
|---|---|
| `W` | 畫 BBox |
| `E` | 畫旋轉框 |
| `V` | 選取 / 編輯模式 |
| `Z` / `X` | 選取的框逆時針 / 順時針旋轉 1° |
| `Shift+Z` / `Shift+X` | 選取的框旋轉 15° |
| `T` | 選取的框在 BBox 與旋轉框之間切換 |
| `1`–`9` | 切換類別（有選取框時會同時變更它的類別） |
| `Delete` | 刪除選取的框 |
| 方向鍵 | 微調位置 1px（加 `Shift` 為 10px） |
| `Ctrl+C` / `Ctrl+V` | 複製 / 貼上框（可貼到其他圖片） |
| `Ctrl+Z` / `Ctrl+Y` | 復原 / 重做 |
| `A` / `D` | 上一張 / 下一張 |
| `F` | 圖片符合視窗 |
| `L` | 切換標註顯示：全部顯示 → 只顯示選取框的標籤 → 只顯示框 → 全部隱藏（只看圖片）。也可從 **檢視 → 標註顯示** 或工具列的「顯示」按鈕選擇。框很多時建議用「只顯示選取框的標籤」（選取模式下滑鼠移到框上也會顯示）；「全部隱藏」時只有正在編輯的框會顯示，隱藏的框點不到 |

| 滾輪 / `Shift` + 滾輪 | 上下 / 左右捲動 |

### 類別管理

在右側 **類別** 面板中：

- **＋ 新增**：新增類別
- **改名**：重新命名（也可雙擊類別）
- **顏色**：變更框的顏色
- **刪除**：刪除類別，會一併刪除所有圖片中這個類別的框

每個類別右側會顯示它在所有圖片中的 **框數量**，編輯時即時更新；滑鼠停在類別上可看到框數與分布在幾張圖片。

## 產生資料集（Ctrl+E）

視窗右側會即時預覽擴增結果：左上為原圖，其餘為隨機擴增樣本。按 **換一張圖片** 或 **重新隨機** 可以看其他結果。

1. **切分**：設定 Train / Valid / Test 比例和亂數種子。可勾選略過沒有標註的圖片。
2. **前處理**（套用到所有切分）：
   - Resize：不調整、拉伸，或等比例縮放並補黑邊
   - 轉灰階
3. **幾何擴增**（只套用到 Train，框會跟著轉換）：水平翻轉、垂直翻轉、90° 旋轉、任意角度旋轉、剪切、縮放、隨機裁切、左右 / 上下平移。
   - **平移**：分別設定 X、Y 方向最多隨機移動幾個像素（以前處理後的圖片為準），移開的區域補黑色。
   - **允許框超出邊界**：不勾選時會自動限制平移量，讓所有框完整留在圖內；勾選後可自由平移，超出的部分會被裁掉，並依「框保留門檻」決定是否保留。
4. **色彩 / 像素擴增**（只套用到 Train）：亮度、曝光、對比、飽和度、色相、灰階、模糊、雜訊。
5. **輸出**：
   - 每張 Train / Valid 圖輸出數量（包含原圖，最多 100）；Test 固定輸出 10 張
   - 框保留門檻：擴增後框留在圖內的面積低於此比例就捨棄
   - 匯出格式，可多選

按 **產生版本** 開始匯出。完成後可直接開啟輸出資料夾。

產生圖片時會用多個行程平行處理（每個行程有自己的 Python GIL，可用滿多核心）。「輸出」群組的 **平行處理數** 設 0 表示自動（約等於實體核心數；圖片運算用超執行緒幫助不大），也可以自己指定。不論用幾個行程，同樣的設定與亂數種子產生的檔案都完全相同。

### 拼接擴增

對話框左側有兩個分頁：上面的設定在 **一般擴增** 分頁；**拼接擴增** 分頁則是把多張小圖拼成大圖：

1. 每張原圖裁出「容納所有標註框的方框」（可加外擴 px）當作一個圖塊。
2. 每張大圖隨機挑 N ± k 個圖塊（例如 12 ± 2 → 10~14 個），做翻轉、90° 旋轉、任意角度旋轉、縮放，框會跟著轉換。原圖不夠時會重複使用，但同一張的每份複本角度至少差 30°。
3. 隨機貼到使用者設定大小的背景上（例如 1624×1240）。可允許圖塊背景互相重疊，但**標註框一定不會被蓋住**；找不到空位時圖塊會逐步縮小再試（可設定最小比例），縮到最小仍放不下才少放。比背景大的圖塊會自動縮小。空白處填入所用圖塊邊緣的平均色。
4. 色彩 / 像素擴增可以選擇每個圖塊各自隨機，或整張拼接圖一起套用。

| 設定 | 說明 |
|---|---|
| 背景範圍 寬 × 高 | 輸出圖片大小，64 ~ 8192 px |
| 產生張數 Train / Valid / Test | 每個切分各產生幾張拼接圖（Test 預設 10） |
| 每張拼接張數 N ± k | 每張拼接圖隨機用 N−k ~ N+k 個圖塊 |
| 允許圖塊背景互相重疊 | 勾選：背景可重疊、標註框不被蓋住；不勾：圖塊完全不重疊 |
| 最小縮放 % | 圖塊找不到空位時最多縮到原本的幾 %（100 = 不縮小） |
| 裁切外擴 px / 間距 px | 圖塊比框多裁的邊；標註框周圍（或不重疊時圖塊之間）至少留的距離 |

切分方式：先依 **一般擴增** 分頁的比例與亂數種子切原圖，每個切分只用自己的圖塊拼接，同一張原圖不會同時出現在 Train 和 Test。灰階與匯出格式也沿用 **一般擴增** 分頁；Resize 不套用。原圖可以是任何大小，大小不一也沒關係。

### 匯出格式

| 格式 | 標註內容 | 說明 |
|---|---|---|
| YOLO | `cls cx cy w h`（正規化） | 旋轉框會轉成外接矩形 |
| YOLO-OBB | `cls x1 y1 x2 y2 x3 y3 x4 y4`（正規化） | 可直接用於 ultralytics 旋轉框訓練；BBox 視為 0° 旋轉框 |
| DOTA | `x1 y1 ... x4 y4 類別名稱 difficult`（像素） | BBox 視為 0° 旋轉框 |
| COCO JSON | `bbox`、4 點 `segmentation` | 旋轉框另有 `rbox: [cx, cy, w, h, angle]` |
| COCO-OBB | `segmentation`（4 個順時針頂點，像素）、外接 `bbox`、多邊形 `area`、`category_id` 從 0 開始 | 給 PaddleDetection PP-YOLOE-R 使用；BBox 視為 0° 旋轉框 |

輸出資料夾結構（以 YOLO 為例）：

```
v1_20261105_103000/
├── data.yaml
├── version.json        # 本次設定，可用來重現
├── train/images, train/labels
├── valid/images, valid/labels
└── test/images,  test/labels
```

COCO-OBB 的結構不同，Valid 會輸出成 `val`：

```
coco_obb/
├── train/images
├── val/images
├── test/images
└── annotations/
    ├── train.json
    ├── val.json
    └── test.json
```

選擇多種格式時，每種格式各放在一個子資料夾。

## 匯入既有標註

**檔案 → 匯入標註**，選擇放 `.txt` 標註檔的資料夾（檔名需與圖片相同）。

- 自動辨識 YOLO、YOLO-OBB、DOTA 格式
- 若資料夾內有 `classes.txt` 或 `data.yaml`，會使用其中的類別名稱
- 可選擇取代或附加到現有標註

### 直接開啟已標好 YOLO-OBB / DOTA 的資料夾（補標 / 修正）

適合先用自動標註（例如 SAM3）產生 `.txt`，再人工補標：

1. 圖片與同檔名的 `.txt` 放在同一個資料夾。支援兩種格式，開啟時自動判斷：
   - **YOLO-OBB**：`cls x1 y1 x2 y2 x3 y3 x4 y4`（正規化），類別名稱放在 `classes.txt`（一行一個，第 N 行 = 類別 N）。
   - **DOTA**：`x1 y1 x2 y2 x3 y3 x4 y4 類別名稱 difficult`（像素）；可有 `imagesource:` / `gsd:` 檔頭。有 `classes.txt` 時依它排列類別順序。
2. 用 **開啟資料夾** 開啟它。若資料夾還沒有 RotaLabel 標註，會自動載入所有標註。四個點不是正好長方形時，會轉成剛好包住它的最小旋轉矩形。
3. 照常新增 / 刪除 / 調整框。修改後的標註 **以相同格式寫到另一個資料夾** `<圖片資料夾>/rotalabel_labels/`（YOLO-OBB 另附 `classes.txt`），**圖片旁的原始 `.txt` 不會被修改**。視窗標題會顯示目前的輸出格式與資料夾。

```
<圖片資料夾>/
├── 001.jpg, 001.txt, classes.txt   # 自動標註的原始結果（唯讀）
└── rotalabel_labels/
    ├── 001.txt                      # 修改後的標註
    └── classes.txt
```

### 標註輸出設定（檔案 → 標註輸出設定…）

可隨時改變修改後標註的 **格式**（YOLO-OBB / DOTA）與 **資料夾**。按確定後，所有已標註的圖片會以新設定重新寫出一次；舊輸出資料夾的檔案會保留。資料夾不能設為圖片資料夾本身（避免蓋掉原始標註）。

注意：

- 原始標註只在第一次開啟（資料夾內還沒有 RotaLabel 標註）時自動載入；之後以 RotaLabel 的標註為準。若重新跑了自動標註，請刪除 `rotalabel_project/` 與 `rotalabel_labels/` 再開啟，或用「匯入標註」取代。
- 內容為空的原始 `.txt`（自動標註沒找到物件）也會被視為已標註的圖片，輸出一個空的 `.txt`。

## 檔案位置

所有資料都存在圖片資料夾內：

```
<圖片資料夾>/rotalabel_project/
├── project.json        # 類別與設定
├── annotations/        # 每張圖一個 .json 標註檔
└── versions/           # 產生的資料集
```

每次存檔時，也會在圖片旁邊寫一份同檔名的 DOTA 標註檔（例如 `001.jpg` → `001.txt`）：

```
imagesource:rotalabel
gsd:null
x1 y1 x2 y2 x3 y3 x4 y4 類別名稱 0      # 像素座標，4 點順時針
```

- 第一行 `imagesource:rotalabel` 是 RotaLabel 的標記；資料夾裡原本就有、不是 RotaLabel 寫的 `.txt` 不會被覆蓋。
- 兩張圖檔名相同、副檔名不同時（例如 `a.jpg`、`a.png`），會改用 `a.jpg.txt`、`a.png.txt`。
- 開啟專案、類別改名時會自動更新；可以用「匯入標註」重新讀回。

舊版（BBoxer）建立的 `bboxer_project/` 資料夾仍可直接開啟使用。

## 其他

- **深色 / 淺色主題**：按工具列右側的 ◐ 按鈕，或選 **檢視 → 切換主題**。

- **測試**：`python -m pytest -q`
